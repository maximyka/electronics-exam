Установка приложения

Работает офлайн без интернета

📲 Инструкция для iPhone (Safari):

  1. Нажмите кнопку «Поделиться» (значок квадрата со стрелкой вверх внизу экрана Safari).
  2. Прокрутите список вниз и выберите «На экран «Домой» (Add to Home Screen).
  3. Нажмите «Добавить» в правом верхнем углу.
  4. Приложение появится как полноценная иконка на рабочем столе и будет открываться без рамок браузера!

💻 Инструкция для Mac (Safari / Chrome):

  1. В Safari: меню Файл → Добавить в Dock.
  2. В Google Chrome: значок установки в адресной строке справа (или меню → Установить приложение).
